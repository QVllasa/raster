Support

Questions, problems or ideas about Raster? Email info@vllasa.com or open an issue on GitHub. We usually reply within two business days.

Where is Raster after launching it?

Raster is a menu bar app and does not appear in the Dock. Its item sits in the top-right of the menu bar; on first launch the panel opens by itself. Click the item to open the panel with all layouts, right-click for a small menu with Settings, “Pause shortcuts” and “Quit Raster”.

Why does Raster ask for the Accessibility permission?

macOS only lets an app move or resize the windows of other apps when you allow it under Accessibility. Raster uses this permission for exactly one thing: reading and setting the position and size of windows. It never reads window contents or your keystrokes. To grant it, open System Settings → Privacy & Security → Accessibility and turn on Raster. The shortcuts work immediately, no restart needed. If Raster still does nothing, remove it from the list with the “−” button, add it again and turn it on – this helps after updating from the GitHub version to the App Store version.

How do I change a shortcut?

Open Settings from the panel (gear button) or the right-click menu. Click the shortcut next to a layout, then press the new key combination. ⌫ removes the shortcut, ⎋ cancels. “Reset” brings back the defaults.

I need ⌘← and ⌘→ in text fields

By default ⌘← and ⌘→ snap windows, which means they no longer jump to the start or end of a line while Raster is running. Two ways out: right-click the Raster item and choose “Pause shortcuts” whenever you need the keys – choose it again to resume. Or assign the halves to different keys in Settings, for example ⌃⌥← and ⌃⌥→.

How does Raster handle multiple displays?

By default, the target is the display under the mouse pointer. In Settings you can switch to the display of the active window instead. ⌃⌥⌘→ and ⌃⌥⌘← move the active window to the next or previous display; its size and position are scaled proportionally. Optionally, pressing a half shortcut twice moves the window to the neighboring display instead of cycling the width.

How do I start Raster automatically?

The App Store version asks you on first launch. You can change it any time in Settings under “Open at login”. The GitHub version enables this automatically; you can turn it off there as well.

How do I quit Raster?

Right-click the Raster item and choose “Quit Raster” – or open Settings and click “Quit”.

Can I have both the App Store and the GitHub version installed?

Please use only one at a time. Both register the same shortcuts, so they would get in each other's way. If you switch, quit the old one, delete it from the Applications folder and grant the Accessibility permission to the new one.

Which languages are supported?

English and German. Raster follows the language set in System Settings → General → Language & Region.

System requirements

macOS 26 (Tahoe) or later, on Macs with Apple silicon or Intel. Raster uses the Liquid Glass material of macOS 26 and therefore does not run on older versions.
