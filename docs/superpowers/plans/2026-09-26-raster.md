# Raster Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menüleisten-App „Raster“, die per globalem Kürzel das aktive Fenster (bzw. alle Fenster) auf dem Bildschirm unter der Maus anordnet, mit Liquid-Glass-Panel und Autostart.

**Architecture:** Swift-Package (wie `~/Projects/puls`), ausführbares Target `Raster`. Reine Geometrie (`LayoutMath`, `ScreenGeometry`) ist von AppKit-Zuständen getrennt und über `Raster --selftest` geprüft; `WindowManager` verbindet Geometrie mit der Accessibility-API; `HotKeyCenter` (Carbon) löst Aktionen aus; SwiftUI-Views in einem `NSGlassEffectView`-Panel.

**Tech Stack:** Swift 6.3 (Sprachmodus 5), AppKit, SwiftUI, Carbon HIToolbox, ApplicationServices (AX), ServiceManagement; macOS 26.

**Spec:** `docs/superpowers/specs/2026-09-26-raster-design.md`

## Global Constraints

- Plattform `.macOS("26.0")`, `swift-tools-version: 6.0`, `swiftLanguageModes: [.v5]`, keine Fremd-Abhängigkeiten.
- Bundle-ID `io.github.qvllasa.raster`, `LSUIElement = true`, Version aus `VERSION` (1.0.0).
- Alle UI-Texte deutsch mit korrekten Umlauten; Kommentarstil wie Puls (knappe deutsche Doc-Kommentare).
- Standardkürzel exakt laut Spec-Tabelle; ⌘← / ⌘→ / ⌘↑ = linke Hälfte / rechte Hälfte / Maximieren.
- Standard-Einstellungen: Zielbildschirm Maus, erneutes Drücken „Breite wechseln“, Abstand 0, Autostart an.
- Koordinaten: intern für Fenster immer AX/CG-System (Ursprung oben links am Hauptbildschirm, y nach unten).
- Signatur: Identität „Raster Local Signing“ aus `~/Library/Keychains/raster-signing.keychain-db` (Passwort `raster`), Fallback ad hoc.

## Review Focus

1. Fenster mit Mindestgröße größer als die Zielfläche (z. B. Systemeinstellungen) → bleibt vollständig auf dem Bildschirm, an der gewünschten Kante ausgerichtet. Test: `testClampKeepsEdge` (Task 1).
2. Bildschirme übereinander/versetzt angeordnet (Nebenbildschirm mit negativem y) → Umrechnung Cocoa↔AX stimmt, Fenster landet auf dem richtigen Bildschirm. Test: `testConversionStackedScreens` (Task 2).
3. Maus exakt auf der Grenze zweier Bildschirme bzw. in einer Lücke → deterministisch ein Bildschirm (nächstgelegener). Test: `testMouseOnSeam` (Task 2).
4. ⌘← während der Kürzel-Aufnahme → wird aufgenommen, nicht ausgeführt (HotKeyCenter pausiert). Manuelle Prüfung Task 8.
5. „Alle Fenster“ mit 0 bzw. 1 Fenster → 0: Signalton, 1: maximieren. Test: `testGridCounts` (Task 1).

### Task 1: Paket-Gerüst, LayoutMath, Selbsttest

**Files:** Create `Package.swift`, `Sources/Raster/App/main.swift` (vorerst nur `--selftest`), `Sources/Raster/App/SelfTest.swift`, `Sources/Raster/Core/LayoutMath.swift`

**Interfaces — Produces:**
- `enum Region { case fraction(x: Double, y: Double, w: Double, h: Double) }` – Anteile der sichtbaren Fläche, y von oben.
- `enum LayoutMath`:
  - `static func rect(for region: Region, in visible: CGRect, gap: CGFloat) -> CGRect` – äußerer Abstand `gap`, innerer ebenfalls `gap` (Fläche um gap/2 schrumpfen, Zelle um gap/2 einrücken).
  - `static func almostMaximized(in visible: CGRect) -> CGRect` (90 % × 90 %, zentriert), `static func centered(_ window: CGRect, in visible: CGRect) -> CGRect`
  - `static func grid(count: Int, in visible: CGRect, gap: CGFloat) -> [CGRect]` – rows = floor(sqrt(n)), cols = ceil(n/rows); letzte Zeile verteilt ihre Fenster über die volle Breite.
  - `static func columns(count:in:gap:) -> [CGRect]`, `static func focusStack(count:in:gap:) -> [CGRect]` (erstes = linke Hälfte, Rest rechts gestapelt; count 1 → Vollfläche)
  - `static func transfer(_ rect: CGRect, from: CGRect, to: CGRect) -> CGRect` – proportional, Größe auf Ziel begrenzt.
  - `static func clamp(actual: CGRect, target: CGRect, visible: CGRect) -> CGRect` – ist das Fenster größer als verlangt, an der Kante des Ziels ausrichten, die an der sichtbaren Fläche anliegt, und in die Fläche schieben.
- `SelfTest.run() -> Int32` mit `check(_ cond: Bool, _ name: String)`; `main.swift`: `--selftest` → `exit(SelfTest.run())`.

### Task 2: ScreenGeometry

**Files:** Create `Sources/Raster/Core/ScreenGeometry.swift`; Modify `SelfTest.swift`

**Interfaces — Produces:**
- `struct ScreenInfo { let frame: CGRect; let visible: CGRect; let name: String }` (alles AX-Koordinaten), `static func current() -> [ScreenInfo]` aus `NSScreen.screens`.
- `enum ScreenGeometry`:
  - `static func toAX(_ cocoa: CGRect, primaryHeight: CGFloat) -> CGRect` / `toCocoa` (y' = H − maxY), `static func toAX(point:primaryHeight:)`.
  - `static func screenIndex(containing point: CGPoint, in frames: [CGRect]) -> Int` – enthält einer den Punkt (halboffen: minX ≤ x < maxX), sonst nächstgelegener nach Abstand.
  - `static func screenIndex(for window: CGRect, in frames: [CGRect]) -> Int` – größte Schnittfläche, sonst nach Mittelpunkt.
  - `static func neighbor(of index: Int, direction: HorizontalDirection, in frames: [CGRect]) -> Int?` – `enum HorizontalDirection { case left, right }`; nächster Mittelpunkt strikt links/rechts.
  - `static func cycle(from index: Int, step: Int, in frames: [CGRect]) -> Int` – Reihenfolge nach minX, dann minY, zyklisch.
- [ ] **Step 1: Tests:** `testConversion` (Cocoa (0,0,1512,982) ↔ AX gleich; Cocoa (0,900,100,82) bei H=982 → AX y=0), `testConversionStackedScreens` (Zweitbildschirm über dem Hauptbildschirm, Cocoa y=982 h=1440 → AX y=−1440), `testMouseOnSeam` (Punkt x=1512 bei Bildschirmen [0..1512] und [1512..4072] → Index 1; Punkt in Lücke → nächster), `testWindowScreen` (70 % Überlappung gewinnt), `testNeighbor` (links/rechts, am Rand nil), `testCycle`.
