Privacy Policy

Last updated: 26 September 2026

In short

Raster does not collect personal data and does not open any network connection – not for updates, not for analytics, not for anything else. Everything happens locally on your Mac. There is no account, no analytics or tracking, and no advertising.

Data processing in the app

Raster moves and resizes windows. To do so it reads the position and size of the windows on your screen and of the displays connected to your Mac, and sets the new position and size. These values are processed only in memory for the current action and are not stored, logged or transmitted. Your settings – shortcuts, gap, display selection and whether Raster opens at login – are stored locally in the macOS preferences and never leave your Mac.

Accessibility permission

Raster needs the “Accessibility” permission because macOS allows an app to move the windows of other apps only with it. Raster uses this permission exclusively to read and set the position and size of windows. It never reads the contents of windows, the text you type or any other information about other apps. You can revoke the permission at any time in System Settings → Privacy & Security → Accessibility.

No network access

Raster contains no code that connects to the internet: no update check, no crash reports, no usage statistics. The App Store version runs in the App Sandbox without any network permission. The version from GitHub is updated manually by you; the App Store version is updated by Apple.
